## 第一次 API 调用怎么跑通

流程总共四步：选地域开通服务、拿 API Key、配环境变量、发请求。

1. 打开百炼控制台，右上角选好地域，国内用户一般选华北2（北京）；
2. 在体验中心或模型广场在线试用模型，确认效果符合预期；
3. 在 API Key 页面创建密钥，配置到环境变量 DASHSCOPE_API_KEY；
4. 发起第一次调用。

已经有 OpenAI 接口代码的，迁移只改三处：API Key、base_url、模型名。base_url 有个细节值得注意：地址里要带上业务空间 ID，不同地域的 base_url 互不通用，北京、新加坡、法兰克福、东京、香港、弗吉尼亚各是各的，混用会连不上。Python 的最小可用示例长这样（把 {WorkspaceId} 换成你的业务空间 ID）：

python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1",
)
completion = client.chat.completions.create(
    model="qwen3.8-max",
    messages=[{"role": "user", "content": "你是谁？"}]
)
print(completion.choices[0].message.content)
